HTML cơ bản

Ngôn ngữ đánh dấu siêu văn bản — dùng thẻ (tag) để đánh dấu tài liệu

Cấu trúc tài liệu HTML

  • <!DOCTYPE html> — định nghĩa đây là HTML5
  • <html> — phần tử root (gốc) của trang
  • <head> — chứa thông tin meta, không hiển thị
  • <title> — tiêu đề tab trình duyệt
  • <body> — chứa toàn bộ nội dung hiển thị

Cấu tạo 1 thẻ

Mỗi thẻ thường có 3 phần: thẻ mở, nội dung, thẻ đóng.

<p>Nội dung</p>
↑mở   ↑nội dung ↑đóng

Thẻ tự đóng (không cần thẻ đóng): <br>, <img src="x.gif">, <hr>...

Ví dụ dễ hiểu: nếu trang web là 1 căn nhà, <!DOCTYPE html> là giấy phép xây dựng, <html> là toàn bộ khu đất, <head> là bản vẽ kỹ thuật (không ai nhìn thấy khi ở trong nhà), còn <body> mới là căn nhà thật mà khách ghé thăm nhìn thấy.

Danh sách (List)

Thẻ Ý nghĩa
<ol> Ordered list — danh sách có thứ tự (1,2,3...)
<ul> Unordered list — danh sách không thứ tự (dấu chấm •)
<li> List item — mỗi mục trong danh sách (phần tử con của ol/ul)
<dl><dt><dd> Danh sách mô tả: dl định nghĩa, dt tên thuật ngữ, dd mô tả 
<ul>
  <li>Táo</li>
  <li>Chuối</li>
</ul>
<!-- hiển thị: • Táo  • Chuối -->

Bảng (Table)

Thẻ Ý nghĩa
<table> Xác định 1 bảng
<tr> Table row — 1 hàng trong bảng
<th> Table header — 1 tiêu đề cột/hàng (chữ đậm, căn giữa)
<td> Table data — 1 ô dữ liệu trong bảng
<caption> Chú thích cho bảng
<thead><tbody><tfoot> Nhóm nội dung tiêu đề / thân / chân trang bảng
<colgroup><col> Nhóm 1 hoặc nhiều cột trong bảng để định dạng chung
Ví dụ dễ hiểu: <table> là cả bảng, <tr> là 1 hàng ngang, <th>/<td> là từng ô — giống hệt cách bạn đọc 1 bảng Excel: hàng trước, rồi mới đến từng ô trong hàng đó.

Style hoá bảng bằng CSS

Thuộc tính Ý nghĩa
border-collapse separate (mặc định — viền tách rời) hoặc collapse (gộp viền các ô liền kề thành 1 đường duy nhất)
border-spacing Khoảng cách giữa viền các ô liền kề (chỉ có tác dụng khi border-collapse: separate)
tr:nth-child(even) Tô màu xen kẽ (zebra-striping) cho các hàng chẵn — dễ đọc hơn với bảng nhiều dữ liệu 
table { border-collapse: collapse; width: 100%; }
th, td { border: 1px solid #ccc; padding: 8px; }
tr:nth-child(even) { background-color: #f5f5f5; }
📱 Bảng dữ liệu dễ bị tràn ngang trên màn hình nhỏ → bọc <table> trong 1 <div> có overflow-x: auto để cho phép cuộn ngang thay vì vỡ layout

Thẻ hiển thị code trong máy tính

Thẻ Ý nghĩa
<code> Xác định 1 đoạn code ngắn, hiển thị font monospace
<pre> Giữ nguyên định dạng văn bản (khoảng trắng, xuống dòng) đúng như đã gõ — hay dùng kết hợp với <code> cho khối code nhiều dòng
<kbd> Xác định input người dùng gõ từ bàn phím, vd hướng dẫn phím tắt
<samp> Xác định output/kết quả mẫu từ 1 chương trình
<var> Xác định biến/1 đại lượng biểu thức toán học, hiển thị theo font nghiêng 
Nhấn <kbd>Ctrl</kbd> + <kbd>C</kbd> để copy.
Kết quả: <samp>Copied to clipboard</samp>

<pre><code>
function greet() {
  console.log("Hi");
}
</code></pre>

Ký hiệu & Emoji trong HTML

Một số ký tự (như <, >) có ý nghĩa đặc biệt trong HTML nên không gõ trực tiếp được — phải dùng mã thực thể (entity).

Kết quả Tên thực thể Số thực thể
(khoảng trắng không ngắt) &nbsp; &#160;
< &lt; &#60;
> &gt; &#62;
& &amp; &#38;
© &copy; &#169;
® &reg; &#174;
💡 Emoji hiển thị được nhờ trang khai báo bộ ký tự UTF-8 trong <meta charset="UTF-8"> ở <head> 📐 Quy tắc chung: số thực thể luôn bắt đầu bằng &# và kết thúc bằng dấu chấm phẩy (;)

Phần tử mức khối (Block) vs nội tuyến (Inline)

🟦 Block (cấp khối)

Luôn bắt đầu trên 1 dòng mới, chiếm toàn bộ chiều rộng có sẵn. Có thể đặt width/height, margin, padding theo mọi hướng.

Ví dụ: <p>, <div>, <h1>

🟩 Inline (nội tuyến)

Không bắt đầu dòng mới, chỉ chiếm đủ chiều rộng cần thiết. Không đặt được width/height, margin/padding dọc.

Ví dụ: <span>, <a>, <strong>

💡 <div> = thùng chứa cấp khối, dùng làm vùng bọc cho các phần tử khác 💡 <span> = phần tử nội tuyến, dùng đánh dấu 1 đoạn văn bản nhỏ

HTML nâng cao

Semantic HTML, Form, liên kết, iframe và các thuộc tính quan trọng

Semantic HTML (HTML ngữ nghĩa)

Các thẻ mô tả rõ ràng ý nghĩa nội dung cho cả trình duyệt lẫn người đọc code — thay vì chỉ dùng <div> chung chung.

Thẻ Ý nghĩa
<header> Đại diện cho phần tiêu đề, đầu trang (logo, menu điều hướng chính)
<nav> 1 tập hợp các liên kết điều hướng chính
<section> 1 phần/khu vực nội dung của trang (chương, mục tin tức...)
<article> Nội dung độc lập, có thể tồn tại/phân phối riêng biệt (bài blog, tin tức)
<aside> Nội dung phụ, liên quan gián tiếp đến nội dung xung quanh (thanh bên)
<footer> Phần chân trang: bản quyền, liên hệ, sitemap, tài liệu liên quan
<figure><figcaption> Nội dung minh họa độc lập (ảnh, sơ đồ) và chú thích cho nó
<main> Nội dung chính của tài liệu
<time> Xác định ngày / giờ
Lưu ý: có thể lồng <article> trong <section> hoặc ngược lại — không bắt buộc theo 1 chiều. Một trang có thể có nhiều <header>: 1 cho cả trang, và các <article>/<footer> khác cũng có thể có <header> riêng.

Bố cục trang HTML điển hình 

<body>
  <header>...</header>
  <nav>...</nav>
  <section>
    <article>Nội dung bài viết</article>
    <aside>Thanh bên</aside>
  </section>
  <footer>...</footer>
</body>

Thuộc tính class & id

class

Xét kiểu cách giống nhau cho nhiều phần tử có cùng tên class. Trong CSS gọi bằng dấu chấm: .class {} 

<h1 class="class1 class2">

id

Chỉ định 1 id duy nhất cho 1 phần tử — không được trùng trong cùng 1 trang. Trong CSS gọi bằng dấu #: #id {} 

<div id="header">
⚠️ id chỉ dùng 1 lần / trang · class dùng lại được cho nhiều phần tử

Liên kết (Hyperlink) & thuộc tính target 

<a href="https://..." target="_blank">Nội dung liên kết</a>
Giá trị target Ý nghĩa
_self Mặc định — mở tại cùng cửa sổ/tab
_blank Mở tài liệu trong cửa sổ/tab mới
_parent Mở trong parent frame
_top Mở trong toàn bộ nội dung của cửa sổ
🔗 Chưa truy cập: gạch chân + xanh lam 🔗 Đã truy cập: gạch chân + màu tím 🔗 Đang active: gạch chân + màu đỏ

Form — thu thập dữ liệu người dùng

Ví dụ: form đăng nhập, đăng ký, liên hệ...

Các thẻ cơ bản trong <form>

  • <input> — ô nhập liệu (text, radio, submit, email...)
  • <label> — nhãn cho 1 phần tử nhập liệu, thuộc tính for phải khớp với id của input
  • <select><option> — chỉ định 1 dropdown list
  • <textarea> — ô nhập nhiều dòng
  • <button>, <fieldset>, <legend>, <datalist>

Thuộc tính quan trọng

  • action — xác định nơi dữ liệu form được gửi tới
  • method="get|post" — phương thức HTTP gửi dữ liệu
  • name — bắt buộc để dữ liệu input được submit
  • autocomplete="on|off", novalidate 
<label for="email">Email:</label>
<input type="email" id="email" name="email">
<input type="submit" value="Gửi">
GET vs POST — khi nào dùng gì? GET gửi dữ liệu hiển thị ngay trên URL, phù hợp cho tìm kiếm/lọc dữ liệu, không nên dùng khi có thông tin nhạy cảm. POST không hiển thị dữ liệu trên URL, dùng khi gửi thông tin cá nhân/nhạy cảm như mật khẩu.
💡 <iframe src="url"></iframe> — nhúng 1 trang web khác vào trang hiện tại 💡 target của link phải trùng với thuộc tính name của iframe muốn mở vào

Icon với Font Awesome

Font Awesome là thư viện icon miễn phí phổ biến nhất cho web — thay vì tự vẽ hoặc tải ảnh icon, chỉ cần gắn đúng class vào 1 thẻ <i>. 

<head>
  <!-- Đặt script kit ngay trong head -->
  <script src="https://kit.fontawesome.com/yourcode.js"
          crossorigin="anonymous"></script>
</head>

<body>
  <!-- Dùng icon bất kỳ đâu trong body -->
  <i class="fas fa-cloud"></i>
  <i class="fas fa-heart"></i>
  <i class="fas fa-user"></i>
</body>
🔑 Lấy mã "yourcode" riêng bằng cách đăng ký miễn phí tại fontawesome.com 🎨 Icon vẽ bằng font/SVG nên đổi màu, đổi size được y hệt chữ thường: font-size, color 
<i class="fas fa-heart" style="font-size:32px; color:red;"></i>
Ví dụ dễ hiểu: nhúng Font Awesome giống hệt cách nhúng Bootstrap qua CDN — chỉ cần 1 dòng <script>/<link> trong <head>, không cần tải file về máy, rồi dùng lại class có sẵn ở bất kỳ đâu trong <body>.

CSS nhập môn

Cascading Style Sheets — ngôn ngữ định dạng lại các phần tử HTML

3 cách nhúng CSS

1. Inline CSS

Viết trực tiếp trên chính thẻ HTML qua thuộc tính style. Khó quản lý khi dự án lớn. 

<h1 style="color:red; font-size:20px">
  Hello CSS
</h1>
2. Internal CSS

Viết trong thẻ <style> bên trong <head> của trang HTML. 

<head>
  <style>
    h1 { color:red; }
  </style>
</head>
3. External CSS ⭐

Tách CSS ra 1 file .css riêng — cách phổ biến nhất, dễ bảo trì. 

<head>
  <link rel="stylesheet"
    href="mystyle.css">
</head>

Cấu trúc 1 rule CSS 

selector {
  thuộc-tính: giá-trị;  /* declaration / khai báo */
}
/* ví dụ: */
h1 {
  color: blue;
  font-size: 20px;
}
🛠️ Chrome DevTools: công cụ kiểm tra web tích hợp sẵn trong trình duyệt Chrome (bấm chuột phải → "Inspect", hoặc phím F12). Giúp xem trực tiếp CSS đang áp dụng cho từng phần tử, sửa thử ngay trên trình duyệt để xem kết quả tức thì — công cụ debug CSS quan trọng nhất mà bất kỳ ai học CSS cũng nên làm quen sớm.

Bộ chọn (Selector) cơ bản

Loại Cú pháp Ý nghĩa
ID #id Chọn phần tử có id="firstname" → #firstname
Class .class Chọn phần tử có class="intro" → .intro
Element tag Chọn tất cả phần tử <p> → p
Element.class tag.class Chỉ chọn <p> có class="intro" → p.intro
Nhóm a, b Chọn nhiều loại phần tử cùng lúc → div, p

Combinator (tổ hợp bộ chọn)

Tên Ký hiệu Ý nghĩa
Descendant div p Chọn mọi <p> nằm bên trong <div> (mọi cấp)
Child div > p Chỉ chọn <p> là con trực tiếp của <div>
Adjacent sibling div + p Chọn <p> đứng ngay sau <div>, cùng cấp cha
General sibling div ~ p Chọn mọi <p> là anh em (cùng cấp cha) đứng sau <div>
Ví dụ dễ hiểu: nếu HTML là 1 cây gia phả, div p là "mọi con cháu", div > p chỉ là "con ruột", div + p là "em kế liền sau", còn div ~ p là "tất cả các em sinh sau" (không nhất thiết liền kề).

CSS với màu sắc

Loại Cú pháp Ghi chú
RGB rgb(255,0,0) Đỏ, lục, lam — mỗi giá trị 0-255
RGBA rgba(255,0,0,.5) Thêm alpha (độ mờ) 0-1
HEX #rrggbb Mã thập lục phân, cao nhất FF, thấp nhất 00 — dùng nhiều nhất
HSL hsl(0,100%,50%) Hue (màu sắc), Saturation (độ bão hoà), Lightness (độ sáng)
HSLA hsla(0,100%,50%,.5) Thêm alpha — độ trong suốt

⭐ Thứ tự ưu tiên (Specificity) & tính kế thừa

Loại rule Thứ tự ưu tiên Phạm vi tác động
inline (style="") 1 (cao nhất) Hẹp nhất — chỉ 1 phần tử
id (#id) 2 Hẹp
class (.class) 3 Rộng
tag (element) 4 (thấp nhất) Rộng nhất
💡 Cùng cấp độ ưu tiên → rule viết sau cùng sẽ thắng 💡 Ghi đè mạnh nhất: color: pink !important; 💡 Thuộc tính kế thừa (như color) đặt ở cha sẽ tự áp cho con
Ví dụ dễ hiểu: specificity giống như "chức vụ" trong công ty ra quyết định — inline là giám đốc, id là trưởng phòng, class là nhân viên, tag là thực tập sinh. Chức vụ cao hơn luôn thắng, bất kể ai "nói" (viết code) trước hay sau.

Pseudo-classes (lớp giả) thường dùng

Bộ chọn Mô tả
:hover Khi di chuột vào phần tử
:active Khi phần tử đang được click
:link / :visited Link chưa/đã từng được truy cập
:first-child / :last-child Phần tử con đầu tiên / cuối cùng trong phần tử cha
:nth-child(n) Phần tử con thứ n (có thể dùng odd/even)
:checked / :disabled Trạng thái của input (đã tick / bị vô hiệu hoá)
⚠️ Quy tắc thứ tự bắt buộc: :link → :visited → :hover → :active (nhớ "LVHA")

🎨 CSS nâng cao — Style hoá Form

Đi sâu hơn CSS nhập môn: pseudo-class trạng thái, pseudo-element, và style hoá form — vì form mặc định của trình duyệt rất xấu

Ở nhánh HTML nâng cao bạn đã học cách TẠO form (input, label, select...). Nhánh này tập trung vào cách ĐỊNH DẠNG form đó bằng CSS — vì mỗi trình duyệt tự vẽ input/checkbox/radio theo kiểu riêng, trông khá thô và không đồng nhất.

1️⃣ Reset style mặc định của input 

input, textarea, select, button {
  font-family: inherit;   /* mặc định input KHÔNG tự kế thừa font của body */
  font-size: inherit;
  border: 1px solid #ccc;
  border-radius: 6px;
  padding: 10px 12px;
  outline: none;          /* bỏ viền xanh mặc định khi click vào */
}
⚠️ Vì sao input không tự có font giống chữ xung quanh? Đây là hành vi mặc định của trình duyệt — input/button/select có font-family và font-size RIÊNG (thường là font hệ thống), không tự kế thừa từ body như thẻ <p> hay <div>. Luôn cần khai báo font-family: inherit; theo thói quen khi style form.

2️⃣ Pseudo-class cho trạng thái input

Pseudo-class Kích hoạt khi nào
:focus Người dùng đang click/tab vào ô input đó
:hover Di chuột qua input (ít dùng hơn :focus với form)
:disabled Input bị vô hiệu hoá (thuộc tính disabled)
:checked Checkbox/radio đang được tick
:required / :optional Input có/không có thuộc tính required
:valid / :invalid Giá trị nhập vào hợp lệ/không hợp lệ theo type hoặc pattern
:placeholder-shown Input đang rỗng, còn hiện chữ placeholder mờ 
/* Đổi viền khi focus — thay thế outline mặc định bằng thứ đẹp hơn */
input:focus {
  border-color: #4fb19d;
  box-shadow: 0 0 0 3px rgba(79,177,157,.25);
}

/* Validation theo thời gian thực — không cần JavaScript! */
input:invalid {
  border-color: #c98c9a;
}
input:valid {
  border-color: #4fb19d;
}
💡 :invalid tự kích hoạt dựa theo type="email"/"url"/"number" hoặc thuộc tính pattern, required — trình duyệt tự kiểm tra, không cần JS ⚠️ input rỗng ban đầu cũng khớp :invalid nếu có required — nên thường kết hợp thêm :placeholder-shown hoặc chỉ tô đỏ sau khi submit bằng JS

3️⃣ ::placeholder — style chữ gợi ý 

input::placeholder {
  color: #aaa;
  font-style: italic;
}
🔗 Đã học ::before/::after ở nhánh Typography — ::placeholder cũng là 1 pseudo-element tương tự, nhắm riêng vào chữ gợi ý trong input

4️⃣ Checkbox & Radio — cách đơn giản nhất

Checkbox/radio rất khó custom hoàn toàn bằng CSS thuần (mỗi trình duyệt vẽ khác nhau). Cách đơn giản và được hỗ trợ tốt nhất hiện nay là dùng accent-color: 

input[type="checkbox"],
input[type="radio"] {
  accent-color: #4fb19d;   /* chỉ 1 dòng — đổi màu tick/chấm tròn */
  width: 18px;
  height: 18px;
}
Khi nào cần custom sâu hơn accent-color? Nếu muốn thiết kế checkbox hoàn toàn khác biệt (hình vuông bo tròn, icon riêng...), kỹ thuật phổ biến là ẩn input gốc bằng appearance: none; rồi tự vẽ giao diện bằng ::before/::after — nhưng với hầu hết dự án học tập, accent-color đã đủ đẹp và đơn giản hơn rất nhiều.

5️⃣ Bố cục Form bằng Flexbox 

.form-group {
  display: flex;
  flex-direction: column;
  gap: 6px;
  margin-bottom: 16px;
}
.form-group label {
  font-weight: 600;
  font-size: .9rem;
}
🔗 Liên hệ nhánh Layout đã học: mỗi cặp label + input là 1 flex-container riêng, xếp dọc bằng flex-direction: column

Ví dụ hoàn chỉnh — Form đăng nhập

Box Model (Mô hình hộp)

Mọi phần tử HTML đều là 1 chiếc hộp gồm 4 lớp: Content → Padding → Border → Margin

4 lớp của Box Model

  • Content — nội dung thật (chữ, ảnh...)
  • Padding — khoảng đệm giữa content và border, thuộc bên trong phần tử
  • Border — viền bao quanh padding + content
  • Margin — khoảng cách ra bên ngoài, giữa phần tử này với phần tử khác

box-sizing

content-box (mặc định): width/height chỉ tính content — padding/border cộng thêm ra ngoài, làm kích thước thực tế lớn hơn số khai báo.

border-box: width/height đã bao gồm cả padding + border — kích thước tổng luôn đúng số bạn set.

Ví dụ dễ hiểu: box model giống 1 hộp quà: content là món quà, padding là lớp xốp chèn quanh quà, border là vỏ hộp cứng, margin là khoảng trống bạn để lại quanh hộp khi xếp nhiều hộp cạnh nhau lên kệ. 
* { box-sizing: border-box; }
/* đặt ở đầu file CSS, dùng * vì box-sizing không tự inherit xuống con
   như color hay font-size */

Công thức tính kích thước thực tế 

Tổng width  = width  + padding-trái + padding-phải + border-trái + border-phải
Tổng height = height + padding-trên + padding-dưới + border-trên + border-dưới

// Ví dụ: width:320px; padding:10px; border:5px solid gray;
// Tổng width = 320 + (10+10) + (5+5) = 350px

Border

Thuộc tính Giá trị / ý nghĩa
border-style solid (liền), dashed (nét đứt), dotted (chấm), double (viền kép), none
border-width Độ rộng viền
border-color Màu viền
border-radius Bo tròn góc viền
Viết tắt border: 5px solid red; (width style color)

Margin vs Padding — khi nào dùng gì?

Margin

Tạo khoảng cách bên ngoài phần tử — dùng để tạo khoảng cách giữa các phần tử/khối với nhau. margin: auto giúp căn giữa phần tử theo chiều ngang (khi đã có width cố định).

Padding

Tạo khoảng cách bên trong phần tử, giữa content và border. Hay dùng với các phần tử có background để nội dung không dính sát viền.

⚠️ Hiện tượng "thu hẹp lề" (margin collapsing): lề dưới của phần tử 1 và lề trên của phần tử 2 chồng lên nhau → chỉ lấy giá trị lớn hơn, không cộng dồn

Outline (khác với border!)

Là đường viền vẽ xung quanh border, dùng làm phần tử nổi bật — không phải 1 phần kích thước của phần tử (không cộng vào tổng width/height).

outline-style Kiểu dáng (giống border)
outline-width thin, medium, thick hoặc px
outline-color Màu viền ngoài
outline-offset Khoảng trắng giữa border và outline

Layout — Float, Flexbox, Grid & Position

3 cách xây dựng bố cục web, cộng với thuộc tính định vị vị trí

2 loại layout

🏗️ Page layout — bố cục chung (header, navbar, content, footer) 🧩 Component layout — bố cục chi tiết cho từng thành phần

1️⃣ Float

Chỉ định phần tử "nổi" sang trái hoặc phải, bị đưa ra khỏi luồng bình thường của tài liệu — các phần tử theo sau sẽ chạy lên bên cạnh nó. 

.box { float: left; }
/* Vấn đề Collapsing: phần tử cha không "nhìn thấy" chiều cao con float
   → khắc phục bằng clear:both hoặc kỹ thuật clearfix */
.clearfix::after { content:""; display:block; clear:both; }
⚠️ clear chỉ có tác dụng trên phần tử block, không hoạt động trên inline

2️⃣ Flexbox (bố cục 1 chiều)

Thuộc tính cho flex-container

  • display: flex — bật chế độ flex
  • flex-direction — hướng trục chính (row/column)
  • justify-content — căn theo trục chính
  • align-items — căn theo trục chéo (vuông góc)
  • flex-wrap — cho phép xuống dòng khi thiếu chỗ
  • gap — khoảng cách giữa items (không phải margin)

Thuộc tính cho flex-item

  • flex-grow — mức độ giãn nở so với item khác
  • flex-shrink — mức độ co lại
  • flex-basis — độ dài khởi điểm
  • flex — viết tắt của basis + grow + shrink
  • order — đổi thứ tự hiển thị mà không đổi code gốc
  • align-self — ghi đè align-items cho riêng item đó
justify-content Ý nghĩa
flex-start (mặc định) Các item dồn về đầu container
flex-end Dồn về cuối container
center Dồn vào giữa
space-between Khoảng cách đều ở giữa các item
space-around Khoảng cách đều trước/giữa/sau mỗi item
space-evenly Khoảng cách hoàn toàn bằng nhau ở mọi vị trí
Ví dụ dễ hiểu: flexbox giống việc xếp ghế trong 1 hàng — justify-content quyết định cả hàng ghế dồn về đâu (trái/phải/giữa/dàn đều), còn align-items quyết định các ghế cao thấp khác nhau được căn theo mép nào (trên/dưới/giữa).

3️⃣ Grid (bố cục 2 chiều)

Grid-line theo 2 trục chia container thành các ô (grid-cell). Khoảng cách giữa các cell gọi là Gutters (xác định bởi gap). 

.container {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 16px;
}
.item {
  grid-column: 1 / 3;   /* chiếm từ line 1 đến line 3 = 2 cột */
  grid-row: 2 / 3;
}
Giá trị đơn vị Ý nghĩa
fr Đơn vị riêng của Grid — 1 phần của không gian có sẵn
auto Tự động theo nội dung
% Theo phần trăm chiều rộng container
repeat(auto-fill, minmax(60px,1fr)) Tự động chèn nhiều cột/hàng nhất có thể tuỳ kích thước container
💡 auto-fit khác auto-fill: khi container lớn hơn tổng item, auto-fit sẽ co gọn & kéo dài item để lấp đầy container

CSS Position — căn chỉnh vị trí

Giá trị Ý nghĩa
static Mặc định — theo luồng tài liệu thông thường
relative Định vị tương đối so với vị trí ban đầu của chính nó
absolute Định vị tương đối so với phần tử cha gần nhất được định vị (không di chuyển khi cuộn màn hình)
fixed Định vị tương đối so với khung nhìn — cố định so với cửa sổ trình duyệt, không di chuyển khi cuộn
sticky Chuyển đổi giữa relative và fixed tuỳ theo vị trí cuộn — "dính" vào 1 vị trí khi cuộn đến đó
💡 top/bottom/left/right dùng để định vị chính xác vị trí cuối cùng khi kết hợp với position

Typography & Hiệu ứng

Font chữ, đơn vị đo, pseudo-elements, navbar và transition

Đơn vị đo trong CSS

Đơn vị Ý nghĩa

Thuộc tính Font

font-weight normal, bold, hoặc 100-900 (400 = thường, 700 = đậm)
font-style normal, italic, oblique
Viết tắt font: ... — gộp các thuộc tính trên

Thuộc tính Text

Căn chỉnh & khoảng cách

  • text-align — left/right/center/justify
  • line-height — chiều cao dòng
  • letter-spacing / word-spacing
  • text-indent — thụt lề dòng đầu

Trang trí & biến đổi

Ví dụ dễ hiểu: muốn bỏ gạch chân mặc định của link <a>, dùng text-decoration: none; — đây là mẹo cực hay dùng khi biến link thành nút bấm.

Pseudo-elements (phần tử ảo)

CSS cho phép "vẽ thêm" nội dung hiển thị mà không cần viết thêm thẻ HTML — bắt buộc phải có thuộc tính content (dù để trống) thì mới hiển thị.

Pseudo-element Ý nghĩa
::before / ::after Chèn nội dung ngay trước/sau nội dung thật của phần tử
::marker Đại diện dấu đầu dòng của <li>
::placeholder Chữ gợi ý mờ trong input
::selection Phần văn bản đang được bôi đen bằng chuột
::first-line / ::first-letter Định dạng riêng dòng đầu / chữ cái đầu của văn bản 
.box::after {
  content: "";
  display: block;
  clear: both;
}

CSS Navigation Bar & hiệu ứng

Thanh điều hướng

Xây từ <ul><li> — bỏ margin/padding/list-style mặc định. Thanh ngang thường dùng display: flex trên <ul>; thanh cố định dùng position: sticky hoặc fixed.

Transition & Opacity

transition: width .4s ease-in-out; tạo hiệu ứng chuyển động mượt khi 1 thuộc tính thay đổi (ví dụ ô tìm kiếm mở rộng khi focus). opacity nhận giá trị 0.0 → 1.0, giá trị càng thấp càng trong suốt. 

input[type=text] {
  width: 30%;
  transition: width 0.4s ease-in-out;
}
input[type=text]:focus {
  width: 100%;
}

list-style — tuỳ biến danh sách

Thuộc tính Ý nghĩa
list-style-type Kiểu dấu đánh dấu: disc, circle, square, decimal, none...
list-style-image Dùng 1 ảnh làm dấu đầu mục thay vì ký hiệu mặc định, vd url("bullet.png")
list-style-position outside (mặc định, dấu nằm ngoài lề) hoặc inside (dấu nằm trong, chữ thụt theo)
Viết tắt list-style: square inside;
💡 Xây thanh điều hướng luôn bắt đầu bằng list-style: none; để bỏ hẳn dấu chấm đầu dòng

Dropdown Menu (thẻ thả xuống)

Kỹ thuật kinh điển: ẩn menu con bằng display:none, dùng position:relative ở phần tử cha và position:absolute ở menu con, rồi hiện ra khi :hover. 

<div class="dropdown">
  <button>Menu ▾</button>
  <div class="dropdown-content">
    <a href="#">Trang chủ</a>
    <a href="#">Giới thiệu</a>
  </div>
</div>
.dropdown { position: relative; display: inline-block; }

.dropdown-content {
  display: none;           /* ẩn mặc định */
  position: absolute;      /* định vị theo .dropdown (cha) */
  right: 0;                /* cố định menu con phải: right:0 */
  background: white;
  min-width: 160px;
  box-shadow: 0 4px 10px rgba(0,0,0,.15);
}

.dropdown:hover .dropdown-content {
  display: block;          /* hiện khi hover vào .dropdown */
}
Vì sao cần position: relative ở .dropdown? Đã học ở nhánh Layout — position: absolute định vị theo phần tử cha GẦN NHẤT đang được định vị (không phải static). Đặt relative ở .dropdown để menu con absolute bám đúng theo vị trí nút bấm, thay vì bám theo cả trang.
🔎 [attribute] — chọn phần tử có thuộc tính đó, vd a[target] 🔎 [attribute="value"] — giá trị khớp chính xác 🔎 [attribute*="value"] — chứa 1 chuỗi cụ thể 🔎 [attribute^="value"] — bắt đầu bằng giá trị

📱 Responsive Design

Làm 1 trang web hiển thị đẹp trên mọi kích thước màn hình — điện thoại, tablet, laptop, màn hình lớn
Ví dụ dễ hiểu: responsive design giống 1 chiếc áo thun co giãn — vừa vặn với người gầy lẫn người to con, thay vì may riêng từng cỡ áo (từng thiết kế riêng cho từng loại màn hình).

1️⃣ Viewport meta tag — bắt buộc phải có 

<meta name="viewport" content="width=device-width, initial-scale=1.0">
⚠️ Thiếu dòng này, điện thoại sẽ hiển thị trang ở kích thước desktop rồi thu nhỏ lại — chữ bé tí, phải zoom tay 💡 width=device-width: chiều rộng trang = đúng chiều rộng màn hình thật; initial-scale=1.0: mức zoom ban đầu 100%

2️⃣ Media Query — thay đổi CSS theo kích thước màn hình 

/* Mặc định — áp dụng cho MỌI kích thước */
.box { width: 100%; }

/* Chỉ áp dụng khi màn hình rộng TỪ 768px trở lên */
@media (min-width: 768px) {
  .box { width: 50%; }
}
Cú pháp Ý nghĩa
@media (min-width: Xpx) Áp dụng khi màn hình rộng từ Xpx trở lên
@media (max-width: Xpx) Áp dụng khi màn hình hẹp tới Xpx trở xuống
@media (min-width: X) and (max-width: Y) Chỉ áp dụng trong khoảng từ X đến Y
@media (orientation: landscape) Khi màn hình đang xoay ngang

3️⃣ Breakpoint phổ biến (mốc kích thước hay dùng)

Thiết bị Chiều rộng thường gặp
📱 Điện thoại < 576px
📱 Điện thoại lớn / phablet 576px – 767px
📟 Tablet 768px – 991px
💻 Laptop 992px – 1199px
🖥️ Màn hình lớn ≥ 1200px
🔗 Liên hệ với Bootstrap: đây chính xác là các mốc sm/md/lg/xl đã học ở nhánh Bootstrap 5 — Bootstrap chỉ đơn giản là đóng gói sẵn các media query này thành class (col-md-6...) để bạn không phải tự viết @media tay.

4️⃣ Mobile-first vs Desktop-first

📱 Mobile-first (khuyên dùng)

Viết CSS mặc định cho điện thoại trước, dùng min-width để MỞ RỘNG dần lên màn hình lớn hơn. 

.box { width: 100%; }        /* mobile */
@media (min-width: 768px) {
  .box { width: 50%; }       /* tablet+ */
}

🖥️ Desktop-first

Viết CSS mặc định cho desktop trước, dùng max-width để THU HẸP dần xuống màn hình nhỏ hơn. 

.box { width: 50%; }         /* desktop */
@media (max-width: 767px) {
  .box { width: 100%; }      /* mobile */
}
⭐ Mobile-first thường được khuyên dùng hơn: hơn 50% traffic web hiện nay đến từ điện thoại, code cũng gọn hơn vì thêm tính năng dần thay vì gỡ bớt

5️⃣ Đơn vị co giãn (tránh dùng px cứng)

Đơn vị Khi nào dùng
% Kích thước theo phần trăm phần tử cha — hay dùng cho width
rem / em Font-size, spacing — co giãn theo gốc <html> hoặc phần tử cha (đã học ở nhánh Typography)
vw / vh Theo % chiều rộng/cao khung nhìn — hay dùng cho hero section full màn hình
minmax(), clamp() Đặt khoảng min-max linh hoạt, tự co giãn không cần viết nhiều media query 
/* clamp(min, giá-trị-lý-tưởng, max) — font tự co giãn mượt mà */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }

6️⃣ Ảnh & Flexbox/Grid tự responsive 

/* Ảnh không bao giờ tràn khỏi khung chứa */
img { max-width: 100%; height: auto; }

/* Grid tự xuống dòng khi hết chỗ — không cần viết @media */
.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
Liên hệ với Layout đã học: đây chính là repeat(auto-fit, minmax()) ở nhánh Layout — nhiều trường hợp Grid/Flexbox tự responsive được mà không cần viết thêm 1 dòng @media nào.

⚠️ Lỗi hay gặp khi làm responsive

Lỗi Hậu quả
Quên thẻ <meta viewport> Điện thoại hiển thị trang thu nhỏ như desktop, chữ bé xíu
Dùng width cố định bằng px cho container lớn Trang bị tràn ngang (horizontal scroll) trên màn hình nhỏ
Test responsive chỉ bằng cách kéo giãn cửa sổ trình duyệt Không giống hành vi thật trên điện thoại — nên dùng DevTools → Device Toolbar để giả lập đúng thiết bị
Chữ quá nhỏ trên mobile (dưới 14px) Khó đọc, người dùng phải zoom tay

🅱️ Bootstrap 5

CSS framework dựng sẵn — viết giao diện nhanh hơn mà không cần tự viết CSS từ đầu

Bootstrap là gì?

Là 1 thư viện CSS (kèm JS) đóng gói sẵn hàng trăm class và component dựng sẵn (nút bấm, navbar, card, modal...) — chỉ cần gắn đúng class vào thẻ HTML là có giao diện đẹp, responsive ngay, không cần tự viết CSS từ con số 0.

Khi nào nên dùng?

Phù hợp khi cần làm nhanh (MVP, đồ án, landing page), team nhiều người cần giao diện đồng nhất. CSS thuần vẫn thắng khi cần thiết kế riêng biệt, độc đáo, không muốn giao diện bị "trông giống mọi trang Bootstrap khác".

Cách nhúng Bootstrap 5 (qua CDN) 

<head>
  <!-- CSS — đặt trong head -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
        rel="stylesheet">
</head>

<body>
  ... nội dung trang ...

  <!-- JS — đặt trước </body>, cần cho dropdown/modal/carousel -->
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
</body>
💡 Chỉ cần link CDN, không cần cài đặt hay tải file về — giống cách nhúng Fontawesome đã học ở HTML nâng cao ⚠️ Thiếu file JS thì các component cần tương tác (dropdown, modal, carousel, toast) sẽ không hoạt động

1️⃣ Grid System — chia bố cục 12 cột

Bootstrap chia mỗi hàng thành 12 cột ảo. Cấu trúc bắt buộc: container → row → col-*. 

<div class="container">
  <div class="row">
    <div class="col-4">Cột 1 (4/12 ≈ 33%)</div>
    <div class="col-8">Cột 2 (8/12 ≈ 67%)</div>
  </div>
</div>
Breakpoint Class Áp dụng từ màn hình rộng
Extra small col-* Mọi kích thước (mặc định)
Small col-sm-* ≥ 576px
Medium col-md-* ≥ 768px
Large col-lg-* ≥ 992px
Extra large col-xl-* ≥ 1200px 
<div class="col-12 col-md-6 col-lg-4">...</div>
// Điện thoại: chiếm 12/12 (full hàng)
// Tablet trở lên: chiếm 6/12 (nửa hàng)
// Laptop trở lên: chiếm 4/12 (1/3 hàng)
Ví dụ dễ hiểu: grid system giống việc chia 1 chiếc bánh pizza thành 12 miếng cố định — bạn chỉ cần nói "tôi lấy 4 miếng", Bootstrap tự tính ra đó là bao nhiêu % chiều rộng, tự responsive theo từng kích thước màn hình mà không cần viết media query tay.

2️⃣ Utility classes — thay thế CSS viết tay

Nhóm Ví dụ class Tương đương CSS
Spacing m-3, p-2, mt-4, px-5 margin/padding theo thang 0-5
Text text-center, text-primary, fw-bold text-align, color, font-weight
Display d-flex, d-none, d-md-block display: flex/none/block (theo breakpoint)
Màu nền bg-primary, bg-light, bg-dark background-color theo bảng màu Bootstrap
Bo góc / đổ bóng rounded, rounded-circle, shadow border-radius, box-shadow
💡 m/p = margin/padding, số 0-5 = mức độ (0 = không có, 5 = lớn nhất), t/b/s/e = top/bottom/start(trái)/end(phải)

3️⃣ Component dựng sẵn hay dùng nhất

Button

Nút bấm với nhiều màu/kích cỡ dựng sẵn.

<button class="btn btn-primary">
  Đăng nhập
</button>
Navbar

Thanh điều hướng responsive, tự thu gọn thành menu hamburger trên mobile. 

<nav class="navbar navbar-expand-lg">
  ...
</nav>
Card

Khung chứa nội dung có viền + bóng đổ, hay dùng cho danh sách sản phẩm/bài viết. 

<div class="card">
  <div class="card-body">...</div>
</div>
Alert

Hộp thông báo màu sắc theo ngữ cảnh (thành công, lỗi, cảnh báo). 

<div class="alert alert-danger">
  Sai mật khẩu!
</div>
Modal

Cửa sổ pop-up — có sẵn hiệu ứng, overlay, đóng bằng Escape, không cần tự viết JS. 

<button data-bs-toggle="modal"
  data-bs-target="#myModal">
  Mở
</button>
Form

Input, label, select được style sẵn đồng bộ.

<input class="form-control"
  type="text">
🔗 Liên hệ với JS đã học: Bootstrap Modal hoạt động gần giống hệt dự án Modal Window đã làm ở trang JavaScript (ẩn/hiện qua class, có overlay, đóng bằng Escape) — chỉ khác là Bootstrap đã viết sẵn toàn bộ JS đó cho bạn, chỉ cần gắn đúng thuộc tính data-bs-toggle / data-bs-target, không cần tự viết addEventListener.

Ví dụ hoàn chỉnh — Navbar + Card dùng Bootstrap 

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">MyLogo</a>
  </div>
</nav>

<div class="container mt-4">
  <div class="row">
    <div class="col-12 col-md-4 mb-3">
      <div class="card shadow-sm">
        <div class="card-body">
          <h5 class="card-title">Sản phẩm A</h5>
          <button class="btn btn-primary">Mua ngay</button>
        </div>
      </div>
    </div>
    <!-- lặp lại col-md-4 để có 3 card / hàng trên desktop -->
  </div>
</div>

⚠️ Lưu ý khi dùng Bootstrap

Vấn đề Giải thích
Specificity xung đột CSS tự viết đè lên Bootstrap có thể không ăn nếu Bootstrap có class cụ thể hơn — nhớ lại nhánh Specificity đã học, cần selector cụ thể hơn hoặc !important
File nặng hơn CSS thuần Tải cả thư viện dù chỉ dùng vài class — có thể tối ưu bằng cách chỉ import đúng module cần (khi build bằng Sass)
Giao diện dễ "giống nhau" Nhiều trang dùng Bootstrap mặc định trông khá giống nhau — nên tuỳ biến thêm bằng CSS riêng hoặc đổi biến Sass
Component cần JS phải nhúng đủ bundle.js Modal, dropdown, toast, carousel không hoạt động nếu quên nhúng file JS ở cuối trang
